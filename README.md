# AWS Static Website Hosting Project

## Project Overview
This project demonstrates static website hosting using AWS cloud services.

## Services Used
- Amazon S3
- CloudFront
- IAM

## Features
- Static website hosting
- HTTPS enabled
- CDN acceleration
- Secure public access

## Architecture
User → CloudFront → S3 Bucket
